# TESTING-v5 — живой прогон полного покрытия

Проверяет SPEC-v5 (фазы 5.1–5.6). Сервер — `scripts/test-server.sh`, выживание, мирная сложность,
кроме пунктов с мобами. Предметы — `/give` через RCON, пока игрок в игре.

**Главный критерий.** Счётчик непокрытого на остановке после всего прогона содержит только:
- `direct_new_item` — ноль (`/give` теперь `cmd_give`);
- `item_spawn` — только заведомые дыры SPEC-v5 §5 и команды по блокам;
- `item_vanished` — ноль.

Каждое расхождение — строка в TESTING-v5-RESULTS с офлайн-разбором (`Scan.java`, `Forms.java` в
scratchpad прошлого прогона: копия `ledger/`, строки нужных причин, формы в имена).

Формат: пункт — что делать — что ожидать (причина, держатели).

---

## 5.1 Использование

- **U1.** Костная мука на саженец → `bonemeal_use`, рука → Void.
- **U2.** Светокамень в якорь (не взрывать) → `item_into_single_block`.
- **U3.** Око в рамку портала Энда (рамку поставить командой) → `eye_into_frame`.
- **U4.** Соты на медный блок → `wax_apply`.
- **U5.** Яйцо призыва свиньи на землю → `spawn_egg_use`.
- **U6.** Огненный заряд по незераку → `item_used`.
- **U7.** Ведро воды: вылить, набрать; ведро лавы; молоко с коровы → `bucket_empty` / `bucket_fill`,
  превращение в слоте, без `item_vanished` и `direct_new_item` (было D10).
- **U8.** Рыба в ведро, выпустить → `bucket_capture_mob` / `bucket_release_mob`.
- **U9.** Бутылочка из воды, из котла; зелье в котёл; отмыть кожаную броню → `bottle_fill` / `bottle_empty`
  / `cauldron_wash`.
- **U10.** Маяк: оплата слитком → `beacon_payment` со слота маяка.
- **U11.** Удочка с морковкой до поломки (`/give` с износом почти до конца) → `transmute_on_break`.
- **U12.** Pick-block в выживании → `hotbar_swap`; ПКМ шлемом в руке при надетом → `equip_armor`.
- **U13.** Раздатчик: костная мука, ведро воды, бутылочка перед водой, динамит, стрела, алмаз →
  `dispenser_behavior` (трата и превращение), `dispensed_projectile`, `dispenser_eject`; баланс слотов
  раздатчика сходится с `/pp lookup` по его позиции.

  Выстрел в моба (стрела исчезает) → `proj_hit_void`. Стрела в стене до деспавна (1 мин) → `proj_despawn`.

  торчащей стрелой — после старта подбор всё ещё из слота стрелы (метка пережила перезапуск).
- **P5.** Арбалет: зарядка, выстрел, подбор → `crossbow_load` (превращение), `crossbow_shoot`,
  `proj_pickup`.
- **P6.** Фейерверк с земли и на элитрах → `firework_launch`.

## 5.5 Команды и творческий режим

- **C1.** `/give`, `/clear`, `/enchant`, `/item replace entity`, `/loot give` из консоли, через RCON и из
  чата → `cmd_*`; призрачный предмет `/give` не попадает в `item_spawn`.
- **C2.** Творческий режим: взять из меню, выбросить из меню, pick-block → `creative_set`,
  `creative_pick`.
